# 美術參考與製作方向

## 使用者指定參考

https://www.youtube.com/watch?v=ApIO-kEAuy4

狀態：2026-10-05，雲端 HTTPS CONNECT 代理回覆 403，尚未觀看影片、取得畫面或確認影片標題。現有素材並非根據這支影片製作。

可讀取影片或使用者提供畫面後，先整理以下觀察，再逐項調整模型：

- 角色：身高與頭身比例、盔甲體積、遠距可辨識的輪廓。
- 武器：握持方向、相對角色的長度、攻擊動作所需的支點。
- 陣營：主色與輔色、旗幟、遠距辨識方式。
- 戰場：角色相對地形的尺度、路線寬度、建築尺寸。
- 動作：待機、行走與攻擊的姿勢及時間節奏。

目前已製作原創幾何斥候與石堡場地；先維持可替換的視覺場景，不把美術觀察混入移動或戰鬥規則。影片用於視覺參考，不直接作為模型、材質或音樂來源。
